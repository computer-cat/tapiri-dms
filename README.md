# tapiri-dms

A DMS Plugin that adds touch friendly window controls to your bar. Built for personal use with Zirconium-Jackrabbit

![Preview image](https://github.com/Sylvie00/tapiri-dms/blob/main/assets/preview.png?raw=true)


## How to install
DMS 1.6+: Add this git repo as a custom registry in DMS Settings > Plugins, then install it in Plugin Management.

Alternative install method: Clone the repo and copy the `tapiri-dms` folder to `~/.config/DankMaterialShell/plugins`
